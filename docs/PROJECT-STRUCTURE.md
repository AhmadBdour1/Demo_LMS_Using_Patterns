## Package Responsibilities
- `com.lms.domain.*`: business entities
- `com.lms.repository.interfaces`: persistence contracts
- `com.lms.repository.impl`: in-memory persistence
- `com.lms.service.*`: use-cases and rules
- `com.lms.controller`: thin application boundary
- `com.lms.web`: HTTP + serialization helpers
- `com.lms.common`: enums and shared exceptions
